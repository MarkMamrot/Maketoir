# Integration Approach

Native Xero capability supports retail accounting workflows. Native Shopify capability covers supported product, inventory, order, customer, return and loyalty flows. Cin7 capability supports product, stock and purchasing alignment with clear ownership between systems.

Google Ads, Google Analytics and Meta Ads can provide connected marketing context and analysis where the relevant offering is enabled. Available analysis and governed marketing workflows vary by plan and implementation scope.

Scale and Enterprise include supported standard 3PL workflows, including agreed order hand-off, fulfilment status and inventory synchronization patterns where the provider is supported. Solvantis confirms provider fit and intended workflow during onboarding. Provider-specific connector development, third-party fees, complex warehouse routing and specialist external platforms may be separately scoped and quoted.
