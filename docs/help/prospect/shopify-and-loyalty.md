# Shopify and Loyalty

Solvantis can run one loyalty program across its browser-based POS and a connected Shopify store. Supported Shopify customer, order, return and loyalty flows allow eligible in-store and online activity to contribute to the same customer loyalty experience.

This is part of the native Shopify capability, not a generic promise to build a new connector. The exact migration, customer matching, reward rules and launch sequence are confirmed during onboarding. Connecting a separate third-party loyalty platform is a different requirement and may need discovery, confirmed scope, timing and quotation.
